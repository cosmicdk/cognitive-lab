# 🧠 Cognitive Lab — 思维实验室

> 一个追踪认知基模、支持多模型对比、守护认知发育的开放环境。

---

## 这是什么？

Cognitive Lab 是一款**本地优先、完全开源**的认知发育工具。它不替代你的思考，而是帮你：

- 📊 **看见自己如何思考**——追踪你反复使用的思维框架（认知基模）
- 🔄 **识别重复的推理模式**——在你即将用旧框架得出旧结论时提醒你
- 🧪 **在安全环境中试错**——用不同思维模型并行分析同一问题，事后回溯对比
- 🎮 **你自己掌控一切**——干涉强度、介入领域、数据保留策略，全部由你设定

---

## 为什么需要它？

从六位分析者（架构师、哲学家、工程师、经济学家、社会学家、物理学家）的讨论中，我们提炼了一个核心洞察：

**现有的 AI Skill 全是"手"——帮你执行任务。缺一个"镜子"——帮你看清自己的思维结构。**

但镜子不够。我们还需要：
- **裂缝**——在旧框架即将闭合时中断
- **实验室**——在安全环境里多模型并行测试
- **承诺装置**——帮现在的自己约束冲动的自己
- **反筛选**——不预设用户是哪类人，适配多种认知母语

Cognitive Lab 是这些想法的第一个可运行实现。

## 快速开始

### 安装

```bash
# 克隆仓库
git clone https://github.com/cosmicdk/cognitive-lab.git
cd cognitive-lab

# 安装（推荐使用虚拟环境）
python -m venv venv
source venv/bin/activate
pip install -e .
```

### 第一个认知基模

```bash
# 注册你常用的一个思维框架
cognitive-lab schema add
# 输入：名称"零和博弈框架"
# 输入：描述"倾向于把所有竞争理解为一赢一输"
```

### 记录一次推理

```bash
# 记录你做决策时的思考过程
cognitive-lab chain record
# 输入主题，逐步骤描述你的推理
```

### 多模型对比

```bash
# 创建一个思维实验室案例
cognitive-lab sim create
# 输入你要分析的问题

# 用不同模型分析同一问题
cognitive-lab sim add-run <case_id>
cognitive-lab sim add-run <case_id>  # 再添加一个不同视角

# 对比结果
cognitive-lab sim compare <case_id>
```

### 查看认知变化

```bash
# 生成认知变化摘要
cognitive-lab report

# 导出全部数据
cognitive-lab export ~/my-cognitive-data.json
```

## 架构设计

```
cognitive-lab/
├── core/                    # 核心引擎
│   ├── models.py            # 数据模型（基模、推理链、模拟案例）
│   ├── schema_tracker.py    # 认知基模追踪器（小马"认知镜像层"）
│   ├── pattern_detector.py  # 推理模式检测器（小哲"认知裂缝"触发）
│   ├── simulation_engine.py # 思维实验室引擎（小物"认知风洞"）
│   ├── interference.py      # 干涉决策引擎
│   └── translation.py       # 认知母语适配层（小蛇 R5）
├── storage/
│   └── database.py          # SQLite 本地存储
├── control/                 # 用户控制层
│   ├── preferences.py       # 偏好管理（控制面板）
│   └── commitment.py        # 承诺装置（小静 R4）
├── cli/                     # 命令行入口
│   ├── main.py              # CLI 主程序
│   └── reporter.py          # 报告生成器
├── tests/                   # 测试
├── config.yaml              # 配置文件
├── requirements.txt         # 依赖
├── setup.py                 # 安装配置
└── README.md                # 本文件
```

## 设计原则

1. **本地优先** — 数据存储在你自己的设备上（SQLite）
2. **开源核心** — 所有建模逻辑完全透明可审计
3. **用户完全控制** — 干涉强度从 0（仅观察）到 1（积极挑战）可调
4. **只对比不评判** — 不使用"盲区""错误"等规训标签
5. **渐进式干涉** — 从"只在用户要求时分析"逐步开放
6. **多认知母语** — 支持概念型、经验型、类比型、视觉型表达

## 认知母语示例

同一个概念，用不同"母语"表达：

| 概念 | 概念型 | 经验型 | 类比型 |
|------|--------|--------|--------|
| 认知基模 | 思维框架 | 你常用的思考方式 | 脑子里的地图 |
| 推理模式 | 推理模式 | 你反复使用的思路 | 走熟的老路 |
| 干涉 | 认知干涉 | 一个提醒 | 路口的路标 |
| 模拟 | 思维模拟 | 在脑子里试一遍 | 沙盘推演 |

## 从六位分析到六个工程需求

| 来源 | 核心判断 | 工程实现 |
|------|----------|----------|
| 小马 | 缺认知镜像层 | `schema_tracker.py` — 持久化认知基模图 |
| 小哲 | 缺中断关系 | `pattern_detector.py` — 重复模式识别 |
| 小参 | 缺三体架构 | `core/` + `control/` — 干涉+孵化+控制面板 |
| 小静 | 缺承诺装置 | `commitment.py` — 退出冷却+锁定强度 |
| 小蛇 | 缺反筛选 | `translation.py` — 多认知母语适配 |
| 小物 | 缺思维实验室 | `simulation_engine.py` — 多模型并行对比 |

## 技术栈
